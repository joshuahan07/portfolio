# Joshua Han – Portfolio

Personal portfolio site showcasing my projects and experience. Live at [joshuahan07.github.io/portfolio](https://joshuahan07.github.io/portfolio).

## Features
- Animated hero section and custom interactive components (electric name animation, "Signal Lock" subtitle, "Phosphor Scope" About reveal)
- Featured projects with live demo links: Paralume, Outrank, ThurtenE Carnival App, Great Rivers Demo, OnTrack
- Responsive design for desktop and mobile

## Built With
React, TypeScript, Vite, Tailwind CSS, Three.js

## Running Locally
```
npm install
npm run dev
```
